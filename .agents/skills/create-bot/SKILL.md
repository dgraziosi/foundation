# Create a bot

1. Copy [`bot-template.md`](bot-template.md).
2. Fill Job, Responsibilities, Standards, Routines, Skills, Tools, and Handoffs for the new job. Cite [`.agents/skills/handoff/`](../handoff/) and [`.agents/skills/foundation-mcp/`](../foundation-mcp/) on Skills. Write Handoffs to the handoff skill: who it talks to, and the next-owner rule.
3. Write everyday English. Tester fails a new glossary word that is not a feature name. Feature brands only: Dream, Vault. Url and repo are ordinary words. Link is the edge verb. Record is the node. Activity is the audit log. The user runs Compose. A bot is a named role. Do not mint Replay, Reconcile, Hygiene, Living, Code, Present, Current picture, or Pointer.
4. Paste the result into the user’s harness.
